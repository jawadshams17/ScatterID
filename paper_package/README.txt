Package Contents:

- SUBMISSION_CHECKLIST.txt : Elsevier pre-submission checklist

  └── fig4_sdjwt_patterns.png  (Figure 4: Selective Disclosure SD-JWT Overhead Patterns)

How to Compile on Overleaf:
1. Go to https://www.overleaf.com
2. Click "New Project" -> "Upload Project"
3. Select the provided zip file: `scatterid_2.0_paper_overleaf.zip`
4. Set main document to `main.tex` and click "Recompile" (pdfLaTeX / XeLaTeX).
5. Download your publication-ready PDF!
